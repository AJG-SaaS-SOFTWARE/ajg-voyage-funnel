# AJG Voyage — Kit d’acquisition V1

## Objectif
Obtenir les premiers prospects qualifiés sans publicité payante, mesurer le tunnel réel puis améliorer ce qui bloque.

Tunnel mesuré :

`Visite → formulaire envoyé → clic Calendly → rendez-vous réservé → présentation réalisée → éventuelle inscription`

La priorité V1 n’est pas la portée. C’est la qualité du trafic et le taux de passage d’une étape à l’autre.

## Phase 1 — Validation organique
Cible : 20 à 50 visites qualifiées.

Canaux prioritaires :
1. Instagram
2. Facebook
3. TikTok
4. LinkedIn
5. WhatsApp Status / contacts ayant demandé des informations
6. QR code lors d’échanges physiques

Aucune publicité payante avant d’avoir suffisamment de données pour identifier un message qui convertit.

## Indicateurs à suivre chaque semaine

| Indicateur | Formule | Signal à surveiller |
| --- | --- | --- |
| Taux formulaire | formulaires / visites | intérêt de la landing |
| Taux réservation | RDV / formulaires | friction entre Merci et Calendly |
| Taux de présence | présentations réalisées / RDV | qualité des leads + rappels |
| Taux d’inscription | inscriptions / présentations | efficacité de la présentation |
| Conversion visite → présentation | présentations / visites | KPI global V1 |

Ne pas tirer de conclusion sur moins de 20 à 30 visites par angle de contenu.

## Positionnement éditorial

AJG Voyage ne vend pas une promesse de richesse.

Le contenu doit principalement parler de :
- voyage et comparaison ;
- fonctionnement d’un club de voyage sur adhésion ;
- questions à poser avant d’adhérer ;
- démonstration transparente du parcours ;
- retour d’expérience personnel factuel ;
- possibilité de découvrir l’activité d’ambassadeur sans promesse de revenus.

## CTA principal

> Vous voulez simplement voir comment cela fonctionne ?  
> Le questionnaire prend environ 2 minutes et la présentation est gratuite, sans engagement.  
> https://ajg-voyage.netlify.app/

Utiliser la variante UTM correspondant au canal, définie dans `utm-links.md`.

## Règle de transparence

Lorsqu’un contenu promeut directement Travel Advantage ou peut conduire à une commission, ajouter de manière visible :

> **Contenu commercial / recommandation : je peux percevoir une commission si vous souscrivez via ma recommandation.**

Ne jamais cacher cette mention uniquement dans une liste de hashtags.

## Après 100 visites

Faire une revue des données par :
- source ;
- campagne ;
- contenu ;
- profil du lead ;
- score ;
- réservation obtenue ou non.

Conserver les deux meilleurs angles et abandonner les contenus qui produisent de la portée sans leads qualifiés.
